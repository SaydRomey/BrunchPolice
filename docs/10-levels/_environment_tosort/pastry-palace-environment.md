# Pastry Palace Environment Design

## Identity

Pastry Palace is an ornate dessert-and-bakery level built around elegant pastry structures, rotating machinery, frosting surfaces, and brittle baked goods.

---

## Platform Types

| Platform            | Behavior                                          | Gameplay Use                                 |
| ------------------- | ------------------------------------------------- | -------------------------------------------- |
| Croissant stacks    | Curved static platforms.                          | Basic traversal with decorative silhouettes. |
| Baguette beams      | Narrow horizontal platforms.                      | Precision movement and enemy staging.        |
| Cake tiers          | Large layered platforms.                          | Multi-height combat spaces.                  |
| Rotating mixer arms | Moving platforms rotating around a central mixer. | Timing-based traversal.                      |
| Donut platforms     | Circular platforms, some with holes.              | Jump timing and vertical spacing.            |
| Frosted ledges      | Sticky or slippery depending on frosting type.    | Surface variation.                           |

---

## Hazards

| Hazard                | Type                   | Behavior                                |
| --------------------- | ---------------------- | --------------------------------------- |
| Mixer blades          | Damage hazard          | Rotate in predictable patterns.         |
| Falling pastries      | Moving hazard          | Drop from shelves after warning crumbs. |
| Frosting puddles      | Soft hazard            | Slow player movement.                   |
| Brittle pastry floors | Collapsing platform    | Crack and break after brief contact.    |
| Hot cream jets        | Damage / timing hazard | Shoot from pastry machinery.            |
| Sugar glass shards    | Damage hazard          | Sharp floor or wall danger.             |

---

## Interactions

| Interaction                 | Description                                |
| --------------------------- | ------------------------------------------ |
| Ride rotating mixer arms    | Provides circular movement routes.         |
| Break pastry crust barriers | Opens shortcuts or secret spaces.          |
| Push cake carts             | Creates temporary platforms.               |
| Bounce on sponge cake pads  | Launches player to upper routes.           |
| Toggle frosting valves      | Changes which surfaces are sticky or safe. |

## Ambiance

### Audio

- Mixer whirring.
- Soft bakery bells.
- Pastry puffs.
- Frosting splats.
- Distant clinking trays.
- Crumbling pastry sounds.

### Visual

- Warm golden lighting.
- Frosting highlights.
- Elegant dessert architecture.
- Powdered sugar particles.
- Soft reflections on glaze surfaces.

---

## Recommended Level Formula

- Primary traversal gimmick: rotating mixer-arm platforms.
- Surface modifier: frosting slow zones.
- Moving hazard: falling pastries.
- Verticality tool: sponge cake bounce pads.
- Boss-relevant mechanic: using mixer rotation and frosting valves to control arena flow.
