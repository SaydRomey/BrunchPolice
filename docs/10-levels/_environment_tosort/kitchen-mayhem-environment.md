# Kitchen Mayhem Environment Design

## Identity

Kitchen Mayhem is a chaotic prep-area level built around utensils, steam, counters, cutting boards, and moving kitchen equipment.

---

## Platform Types

| Platform                   | Behavior                              | Gameplay Use                        |
| -------------------------- | ------------------------------------- | ----------------------------------- |
| Countertops                | Stable wide platforms.                | Main navigation and combat footing. |
| Cutting boards             | Medium platforms, sometimes sliding.  | Enemy staging and traversal.        |
| Pot lids                   | Circular moving or tilting platforms. | Timing and unstable footing.        |
| Dish racks                 | Narrow vertical platform structures.  | Climbing and precision movement.    |
| Swinging utensil platforms | Hanging spoons, spatulas, or ladles.  | Gap crossing.                       |
| Kitchen carts              | Pushable or moving platforms.         | Player-controlled positioning.      |

---

## Hazards

| Hazard           | Type                 | Behavior                           |
| ---------------- | -------------------- | ---------------------------------- |
| Chopping knives  | Damage hazard        | Move up and down on a timer.       |
| Steam vents      | Soft / timing hazard | Obscure vision or push the player. |
| Falling pans     | Damage hazard        | Drop after a visual warning.       |
| Burner flames    | Damage hazard        | Turn on and off in patterns.       |
| Rolling cans     | Moving hazard        | Roll across counters.              |
| Dishwater spills | Slippery hazard      | Reduce traction.                   |

---

## Interactions

| Interaction              | Description                             |
| ------------------------ | --------------------------------------- |
| Hide behind pots         | Blocks projectiles or enemy sightlines. |
| Redirect steam vents     | Opens routes or disables hazards.       |
| Push kitchen carts       | Creates mobile platforms or shields.    |
| Knock utensils loose     | Forms temporary bridges.                |
| Activate burner switches | Changes safe and unsafe zones.          |
| Use pot lids as shields  | Blocks certain projectiles.             |

## Background Storytelling

| Layer           | Details                                                             |
| --------------- | ------------------------------------------------------------------- |
| Far background  | Large commercial kitchen silhouettes, glowing ovens, hanging racks. |
| Mid background  | Missing cutlery racks, chaotic prep stations, spilled ingredients.  |
| Near background | Steam pipes, hanging pans, warning signs, loose utensils.           |
| Foreground      | Steam clouds, flour puffs, swinging tools, dish spray.              |

## Ambiance

### Audio

- Clanging pans.
- Chopping sounds.
- Steam hisses.
- Dish crashes.
- Burner clicks.
- Rolling metal cans.

### Visual

- Stainless steel shine.
- Steam clouds.
- Hot burner glow.
- Fast-moving utensil silhouettes.
- Sharp lighting from kitchen equipment.

---

## Recommended Level Formula

- Primary traversal gimmick: moving and swinging kitchen objects.
- Surface modifier: dishwater or grease slipperiness.
- Moving hazard: falling pans or chopping knives.
- Verticality tool: hanging utensils and dish racks.
- Boss-relevant mechanic: using pots, lids, and steam redirects to control the arena.
