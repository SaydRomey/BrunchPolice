# Citrus Cascade Environment Design

## Identity

Citrus Cascade is a bright, kinetic juice-and-waterfall level built around juice streams, citrus platforms, launchers, and slick surfaces.

---

## Platform Types

| Platform                | Behavior                          | Gameplay Use                             |
| ----------------------- | --------------------------------- | ---------------------------------------- |
| Orange-slice platforms  | Curved or wedge-shaped platforms. | Standard traversal with visual identity. |
| Citrus wedge lifts      | Moving triangular platforms.      | Vertical or diagonal movement.           |
| Juice-pipe platforms    | Narrow industrial pipe walkways.  | Precision traversal.                     |
| Floating peel platforms | Light platforms that drift.       | Moving traversal.                        |
| Pulp mats               | Sticky or slowing floor surfaces. | Movement modifier.                       |
| Fountain launchers      | Upward or angled burst platforms. | Vertical traversal.                      |

---

## Hazards

| Hazard               | Type                 | Behavior                              |
| -------------------- | -------------------- | ------------------------------------- |
| Juice jets           | Damage / push hazard | Push or knock the player into danger. |
| Citrus acid pools    | Damage hazard        | Dangerous liquid zones.               |
| Rolling orange peels | Moving hazard        | Roll down slopes or across platforms. |
| Juicer blades        | Damage hazard        | Rotating machinery.                   |
| Pulp traps           | Soft hazard          | Slow player movement.                 |
| Spray bursts         | Timing hazard        | Intermittent area denial.             |

---

## Interactions

| Interaction              | Description                                |
| ------------------------ | ------------------------------------------ |
| Use juice fountains      | Launches the player upward or across gaps. |
| Redirect citrus pipes    | Opens paths or changes hazard direction.   |
| Ride orange-slice lifts  | Moving platform traversal.                 |
| Slide down juice streams | Momentum route with limited braking.       |
| Clear pulp blockages     | Restores machinery or opens secret routes. |
| Trigger juicer gates     | Alternates safe and unsafe paths.          |

---

## Background Storytelling

| Layer           | Details                                                     |
| --------------- | ----------------------------------------------------------- |
| Far background  | Citrus waterfalls, bright groves, juice cascades.           |
| Mid background  | Empty orange juice displays, leaking bottles, citrus pipes. |
| Near background | Sprayers, sliced fruit wheels, pulp tanks.                  |
| Foreground      | Citrus mist, pulp particles, juice droplets.                |

## Ambiance

### Audio

- Juice splashes.
- Citrus squirts.
- Fountain sprays.
- Juicer grinding.
- Fruit peel rolls.
- Waterfall rush.

### Visual

- Bright juice spray.
- Citrus mist.
- Sparkling pulp particles.
- Yellow-orange-green palette.
- Strong highlight glints on wet surfaces.

---

## Recommended Level Formula

- Primary traversal gimmick: juice launchers and streams.
- Surface modifier: slick juice and sticky pulp.
- Moving hazard: rolling orange peels.
- Verticality tool: fountain launchers.
- Boss-relevant mechanic: redirecting juice jets to open safe routes or expose the boss.
