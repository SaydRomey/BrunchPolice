# Egg Factory Frenzy Environment Design

## Identity

Egg Factory Frenzy is an industrial processing level built around conveyors, eggshell platforms, yolk hazards, machinery, and timed factory movement.

---

## Platform Types

| Platform                   | Behavior                            | Gameplay Use                          |
| -------------------------- | ----------------------------------- | ------------------------------------- |
| Conveyor belts             | Push the player and objects.        | Main traversal pressure.              |
| Cracked eggshell platforms | Fragile platforms that may break.   | Commitment and route timing.          |
| Frying-pan lifts           | Moving platforms that rise or tilt. | Vertical traversal.                   |
| Egg-carton ledges          | Modular grid-like platforms.        | Stable but visually distinct footing. |
| Machine arms               | Timed moving or rotating platforms. | Precision movement.                   |
| Sorting trays              | Move on rails through the level.    | Rideable traversal.                   |

---

## Hazards

| Hazard             | Type                          | Behavior                            |
| ------------------ | ----------------------------- | ----------------------------------- |
| Crushing presses   | Damage hazard                 | Slam down on a timer.               |
| Yolk spills        | Slippery hazard               | Reduce traction.                    |
| Egg bombs          | Projectile / explosive hazard | Burst after a delay.                |
| Conveyor drop-offs | Positional hazard             | Push player into pits or machinery. |
| Frying-pan smashes | Damage hazard                 | Large telegraphed strikes.          |
| Shell shards       | Damage hazard                 | Sharp debris on floors or walls.    |

---

## Interactions

| Interaction                     | Description                               |
| ------------------------------- | ----------------------------------------- |
| Reverse conveyors               | Changes traversal routes and object flow. |
| Crack eggshell doors            | Opens passages or shortcuts.              |
| Time movement under frying pans | Core timing challenge.                    |
| Ride sorting trays              | Moves player across factory sections.     |
| Redirect egg chutes             | Changes projectile or platform routes.    |
| Disable presses                 | Creates temporary safe lanes.             |

---

## Recommended Level Formula

- Primary traversal gimmick: conveyor routing.
- Surface modifier: slippery yolk.
- Moving hazard: crushing presses.
- Verticality tool: frying-pan lifts.
- Boss-relevant mechanic: reversing conveyors or redirecting egg chutes.
