# Grease Canyon Environment Design

## Identity

Grease Canyon is a sizzling, high-heat traversal level built around slippery surfaces, rising heat, bacon structures, and grease hazards.

---

## Platform Types

| Platform                | Behavior                                                   | Gameplay Use                                  |
| ----------------------- | ---------------------------------------------------------- | --------------------------------------------- |
| Bacon strip ledges      | Flexible platforms that sag slightly under the player.     | Adds visual motion and light timing pressure. |
| Sizzling griddle plates | Stable but surrounded by heat shimmer and grease splatter. | Safe combat footing inside dangerous zones.   |
| Sausage-link ropes      | Swinging or climbable rope-like traversal elements.        | Vertical routes and gap crossing.             |
| Grease-slick slopes     | Slippery inclined platforms.                               | Momentum-based traversal.                     |
| Bacon scaffolds         | Layered static platforms made from crossed bacon strips.   | Main navigation structure.                    |
| Hot pan lifts           | Moving metal platforms that rise from grease pools.        | Timed traversal over damaging areas.          |

---

## Hazards

| Hazard               | Type                   | Behavior                                          |
| -------------------- | ---------------------- | ------------------------------------------------- |
| Grease pits          | Damage hazard          | Damages or defeats the player on contact.         |
| Grease splashes      | Damage / timing hazard | Periodic arcs of hot grease.                      |
| Heat vents           | Soft hazard            | Obscure vision and force timing.                  |
| Falling bacon slabs  | Moving hazard          | Drop from above after a telegraph.                |
| Bacon curl platforms | Platform hazard        | Curl upward or shrink after being stepped on.     |
| Grease bubbles       | Damage hazard          | Pop from pools and create temporary danger zones. |

---

## Interactions

| Interaction                | Description                                                              |
| -------------------------- | ------------------------------------------------------------------------ |
| Slide across grease trails | Lets the player build momentum but reduces braking control.              |
| Swing from sausage ropes   | Enables vertical and horizontal traversal.                               |
| Trigger bacon curls        | Certain bacon platforms curl upward when stepped on, changing the route. |
| Cool griddle switches      | Temporary safe zones can be created by activating cooling valves.        |
| Knock bacon debris loose   | Falling bacon can damage enemies or create temporary bridges.            |

---

## Background Storytelling

| Layer           | Details                                                                    |
| --------------- | -------------------------------------------------------------------------- |
| Far background  | Canyon walls shaped like fried breakfast foods, orange haze, grease smoke. |
| Mid background  | Abandoned bacon carts, stolen breakfast signs, pig tracks, smoking pans.   |
| Near background | Dripping grease pipes, hanging bacon strips, warning signs.                |
| Foreground      | Heat shimmer, grease bubbles, steam curls, smoky overlays.                 |

## Ambiance

### Audio

- Sizzling grease.
- Bacon crackle.
- Bubbling grease pits.
- Distant pig snorts.
- Metal pan rattles.
- Occasional hot-oil pops.

### Visual

- Orange heat haze.
- Heat shimmer above hazard zones.
- Reflective grease surfaces.
- Smoke plumes.
- Glowing griddle edges.

---

## Recommended Level Formula

- Primary traversal gimmick: slippery grease movement.
- Surface modifier: grease-slick platforms.
- Moving hazard: falling bacon slabs.
- Verticality tool: sausage-link ropes.
- Boss-relevant mechanic: using cooled griddle zones or bacon debris during the Bacon Tornado encounter.
