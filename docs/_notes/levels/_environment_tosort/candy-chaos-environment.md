# Candy Chaos Environment Design

## Identity

Candy Chaos is a saturated dessert level built around bounce, brittle candy, chocolate hazards, and elastic traversal.

---

## Platform Types

| Platform          | Behavior                              | Gameplay Use                         |
| ----------------- | ------------------------------------- | ------------------------------------ |
| Gumdrop platforms | Bounce when landed on.                | Vertical traversal and rhythm jumps. |
| Candy bridges     | Static or brittle paths.              | Basic traversal and collapse timing. |
| Chocolate bars    | Rectangular platforms, some slippery. | Modular platform layouts.            |
| Licorice ropes    | Swinging or climbable elements.       | Vertical and gap traversal.          |
| Cake layers       | Wide soft platforms.                  | Combat arenas and staged encounters. |
| Hard candy discs  | Rotating platforms.                   | Timing challenges.                   |

---

## Hazards

| Hazard               | Type                      | Behavior                       |
| -------------------- | ------------------------- | ------------------------------ |
| Chocolate lava       | Damage hazard             | Dangerous liquid floor.        |
| Brittle candy glass  | Damage / breakable hazard | Can shatter into danger zones. |
| Candy ball rollers   | Moving hazard             | Roll along slopes or tracks.   |
| Sticky caramel pools | Soft hazard               | Slow the player.               |
| Sugar spikes         | Damage hazard             | Sharp candy formations.        |
| Pop candy bursts     | Timing hazard             | Small explosive bursts.        |

---

## Interactions

| Interaction               | Description                                           |
| ------------------------- | ----------------------------------------------------- |
| Bounce on gumdrops        | Core vertical traversal mechanic.                     |
| Break brittle candy glass | Opens routes or drops hazards.                        |
| Swing from licorice ropes | Crosses large gaps or vertical shafts.                |
| Push chocolate blocks     | Creates stairs or cover.                              |
| Melt candy barriers       | Opens alternate paths through environmental triggers. |
| Ride candy rollers        | High-risk movement shortcut.                          |

## Ambiance

### Audio

- Candy pops.
- Chocolate bubbling.
- Wrapper crinkles.
- Gumdrop boings.
- Sugar glass cracks.
- Sticky caramel pulls.

### Visual

- Saturated candy colors.
- Chocolate glow.
- Sparkling sugar particles.
- Glossy hard-candy reflections.
- Bright contrast between safe and hazardous surfaces.

---

## Recommended Level Formula

- Primary traversal gimmick: bounce chains.
- Surface modifier: sticky caramel.
- Moving hazard: candy rollers.
- Verticality tool: gumdrops and licorice ropes.
- Boss-relevant mechanic: breaking candy barriers or using bounce routes to dodge arena attacks.
