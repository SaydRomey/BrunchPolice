# Sticky Syrup Swamp Environment Design

## Identity

Sticky Syrup Swamp is a slow, sticky traversal level built around syrup pools, pancake rafts, amber mist, and movement restriction.

---

## Platform Types

| Platform                 | Behavior                                    | Gameplay Use                            |
| ------------------------ | ------------------------------------------- | --------------------------------------- |
| Pancake rafts            | Floating platforms that drift across syrup. | Moving traversal over dangerous liquid. |
| Syrup-coated logs        | Slow, sticky platforms.                     | Soft movement challenge.                |
| Pancake stacks           | Vertical platform clusters.                 | Staggered climbing routes.              |
| Butter pads              | Slightly slippery bounce or slide surfaces. | Momentum variation.                     |
| Dripping amber platforms | Intermittently sticky platforms.            | Timing and route planning.              |
| Sinking pancakes         | Platforms that descend when stood on.       | Encourages quick movement.              |

---

## Hazards

| Hazard            | Type                   | Behavior                                      |
| ----------------- | ---------------------- | --------------------------------------------- |
| Deep syrup pools  | Damage or reset hazard | Punishes falling or poor raft timing.         |
| Syrup puddles     | Soft hazard            | Slows player movement.                        |
| Dripping syrup    | Timing hazard          | Falls from above in predictable intervals.    |
| Mosquito swarms   | Enemy / soft hazard    | Pressures slow movement zones.                |
| Sinking platforms | Platform hazard        | Disappear after sustained contact.            |
| Syrup bubbles     | Damage hazard          | Pop from below and create brief danger zones. |

---

## Interactions

| Interaction                  | Description                                         |
| ---------------------------- | --------------------------------------------------- |
| Ride pancake rafts           | Main traversal across syrup pools.                  |
| Redirect syrup flows         | Changes raft movement or opens passages.            |
| Bounce off buttered pancakes | Launches player to higher routes.                   |
| Pull syrup valves            | Temporarily drains or redirects hazards.            |
| Use sticky walls             | Allows short-duration wall cling or slowed descent. |

### Visual

- Amber haze.
- Sticky reflections.
- Slow liquid movement.
- Thick syrup strands.
- Warm brown-orange palette.

---

## Recommended Level Formula

- Primary traversal gimmick: pancake raft riding.
- Surface modifier: sticky syrup slowdown.
- Moving hazard: syrup bubbles or sinking pancakes.
- Verticality tool: buttered pancake bounce pads.
- Boss-relevant mechanic: redirecting syrup flow to create safe paths.
