# Brunch Police Organized Notes

This folder reorganizes the uploaded Brunch Police planning and implementation files into a cleaner Markdown knowledge base.

## How to use these notes

Start with `01_Project_Roadmap_and_Structure.md` for the overall development plan, then move into the focused system notes as needed.

The organized notes consolidate overlapping material, especially in the weapon, setup, resource, and player-controller documents. The full original source material is also included in `source_archive/` as Markdown files, copied without content changes.

## Note index

1. `01_Project_Roadmap_and_Structure.md` — development phases, project structure, Godot/C++ setup, and integration direction.
2. `02_Setup_and_Build_System.md` — Makefile strategy, larger project build layout, and multi-platform helper files.
3. `03_Core_Game_Systems.md` — events, timers, resource managers, inventory, save/load, score, and power-ups.
4. `04_Player_Controller_Camera_and_Respawn.md` — movement, advanced platforming, camera, checkpoints, and respawn.
5. `05_Combat_Health_Projectiles_and_Weapons.md` — health, damage, i-frames, projectile logic, weapon categories, level-specific weapons, and Bacon Gun behavior.
6. `06_World_Level_Design_and_Editing.md` — world map, level flow, level editor, tilemaps, minimap, quests, and minigames.
7. `07_Audio_Visual_UI_and_Feedback.md` — sound, ambiance, particle effects, visual feedback, animation, character customization, and debug tools.
8. `08_Implementation_Backlog.md` — suggested build order, cleanup items, and integration risks.
9. `99_Source_Manifest.md` — mapping of original files to organized sections.

## Source archive

Every uploaded `.txt` file has been copied into `source_archive/` as a `.md` file. These archive files preserve the original source text exactly, aside from the file extension.
