
# Player Character Concept: The Rookie Brunch Officer

## Core Identity

The player character should be a **customizable rookie investigator** 
newly appointed as the unofficial **Brunch Police**.  
They are not a fixed hero with a locked gender, name, or silhouette.  
They are a flexible avatar designed to fit the game’s inclusive customization system, 
which already calls for appearance, pronoun, and non-binary options.

|                            |                                                                           |
| -------------------------- | ------------------------------------------------------------------------- |
| **Working title**:         | Rookie Brunch Officer                                                     |
| **Optional default name**: | Avery, Riley, Parker, Quinn, or Sage                                      |
| **Role**:                  | Buffet detective, platforming pursuer, food-crime specialist              |
| **Tone**:                  | Earnest, slightly over-serious, and visually ridiculous in a charming way |
| **Design rule**:           | They should look recognizable even after customization.                   |

---

## Visual Design

### Base Silhouette

The player should have a **small, agile, readable platformer silhouette**:

- Oversized brunch-police cap or visor
- Short utility jacket or apron-coat
- Compact crossbody evidence satchel
- Big expressive eyes or face shape readable at sprite scale
- Chunky shoes for jumping and sliding
- Optional badge shaped like a fried egg, waffle, toast slice, or coffee cup

The silhouette should stay consistent even when the player changes hair, 
skin tone, body type, outfit color, or accessories. 

That gives the character a stable gameplay read while still allowing personalization.

---

### Default Outfit

#### Default look:
A cheerful brunch-uniform hybrid: 
half detective, half diner staff, half arcade mascot.

Core outfit pieces:

- **Egg Badge**: a sunny-side-up badge pinned to the chest
- **Apron-Coat**: a cropped detective coat with apron strings and big pockets
- **Evidence Satchel**: holds crumbs, bacon strips, syrup samples, and suspicious utensils
- **Brunch Police Cap**: soft cap with a tiny siren light, coffee-bean emblem, or waffle-checkered band
- **Non-slip Shoes**: thick soles for grease, syrup, and kitchen-platform traversal
- **Utility Gloves**: used for inspecting plates, grabbing ropes, and handling hot food hazards

The design should feel comedic but functional. 
The player should look like someone who takes brunch crimes much too seriously.

---

## Customization System

### Player-Controlled Options

The player should be able to customize:

| Category     | Options                                                               |
| ------------ | --------------------------------------------------------------------- |
| Name         | Free entry, plus inclusive preset names                               |
| Pronouns     | She/her, he/him, they/them, custom                                    |
| Body type    | Slim, stocky, round, tall, short, athletic, soft-bodied               |
| Skin tone    | Broad range                                                           |
| Hair         | Short, long, curly, shaved, buns, locs, braids, undercut, covered     |
| Face         | Eye shape, brows, mouth style, freckles, glasses                      |
| Outfit color | Main uniform color, trim color, badge color                           |
| Hat          | Cap, visor, chef-bandana, detective fedora, no hat                    |
| Accessory    | Pride pin, coffee pin, toast charm, syrup bottle charm, tiny notebook |
| Voice style  | Optional text-bark style rather than gendered voice                   |

This fits the project’s existing inclusive direction: 
diverse body types, gender expression, pronouns, 
and non-binary support are explicitly part of the preserved systems.

## Gameplay Readability

Because the game shifts between an isometric/top-down brunch hub and 2D side-scrolling levels, 
the player design needs two compatible versions. 

The current design inventory defines the hub as isometric/top-down 
and the levels as 2D side-scrolling platformer spaces.

### Hub Version

In the buffet hub, emphasize:
- Hat shape
- Badge
- Satchel
- Face customization
- Outfit colors
- Small idle animations: note-taking, sniffing suspicious plates, adjusting badge

### Platformer Version

In side-scrolling levels, emphasize:
- Strong silhouette
- Hat/cap outline
- Shoes and jump poses
- Satchel bounce
- Weapon readability
- Bright outline against food-heavy backgrounds

The sprite should remain readable in Grease Canyon, Sticky Syrup Swamp, 
Kitchen Mayhem, Candy Chaos, and other high-clutter food environments.

---

## Personality

The player character should be mostly defined by player choices, 
but the default writing voice can have a consistent base:

### Core traits:
- Overly serious about brunch etiquette
- Genuinely wants fairness at the buffet
- Easily shocked by food crimes
- Brave, but often improvising
- Polite until someone steals all the bacon
- Treats crumbs like forensic evidence

### Sample Dialogue Barks
- "Nobody moves. This plate has been tampered with."
- "That syrup pattern is not accidental."
- "I’m going to need everyone to step away from the waffle station."
- "A clean buffet is a just buffet."
- "Evidence bag. Crumb size: suspicious."
- "That is not how shared bacon works."

---

## Animation Set

### Hub Animations
- Idle: taps pencil against notebook
- Inspect: crouches and magnifies a plate
- Accuse: points dramatically with toast-shaped badge
- Wrong accusation: awkwardly lowers notebook
- Correct accusation: siren light on cap flashes
- Interact: leans in with detective seriousness
- Collect clue: places item in satchel

### Platformer Animations
- Run: satchel bouncing, arms pumping
- Jump: knees tucked, cap lifts slightly
- Double jump: toast-shaped sparkle or coffee steam puff
- Slide: shoes skid with syrup/grease trail
- Hit reaction: badge spins loose, character wobbles
- Weapon fire: exaggerated recoil based on food weapon
- Victory: stamps "CASE CLOSED" in notebook

---

## Customization-Compatible Design Rules

To keep customization manageable, build the character in modular layers:
1. Base body
2. Skin tone
3. Face
4. Hair/head covering
5. Uniform torso
6. Legs/shoes
7. Hat
8. Badge
9. Satchel
10. Accessory/pin
11. Temporary power-up overlay

This lets player identity change while core gameplay readability remains stable.

---

## Power-Up Visual Overlays

Power-ups should modify the player without replacing their identity.

| Power-Up / State   | Player Visual Effect                     |
| ------------------ | ---------------------------------------- |
| Grease Slide       | shiny shoe trails, cap leans backward    |
| Extra Bacon Shield | bacon-ring orbit around body             |
| Butter Boots       | glowing yellow boot soles                |
| Honey Comb         | bees orbit harmlessly for a moment       |
| Vitamin Boost      | citrus sparkle around badge              |
| Rainbow Boost      | rainbow trail from satchel or badge      |
| Bacon Gun equipped | satchel opens into bacon-strip ammo reel |

This connects the player visually to the game’s existing level fantasies: 
bacon, syrup, pastry, kitchen tools, candy, eggs, citrus, and bakery hazards.

---

## Final Character Summary

The player character should be a customizable brunch detective avatar 
with one consistent gameplay identity: 

a rookie officer who investigates buffet crimes in the hub, 
then chases culprits through absurd food-themed platforming levels.

### **Best design direction:**
A compact, expressive, modular character wearing a brunch-police cap, 
apron-coat, egg badge, evidence satchel, and non-slip shoes.

### **Core fantasy:**
"You are the person who takes brunch crimes seriously enough 
to chase a bacon thief through a grease canyon."

### **Key implementation principle:**
Do not overdefine gender, name, body type, or personality. 
Define the role, silhouette, equipment, and animation language; 
let the player define the person.
